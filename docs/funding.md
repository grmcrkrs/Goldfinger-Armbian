# Funding setup

The public README already reserves a visible support section. To add GitHub's
native **Sponsor** button, choose a funding destination first; never commit
payment credentials, account-recovery information, private email addresses, or
API keys.

GitHub supports GitHub Sponsors, Ko-fi, Buy Me a Coffee, Liberapay, Patreon,
Open Collective, Polar, and custom funding URLs through `.github/FUNDING.yml`.
Only the public account name or public donation URL belongs in that file.

Examples—use only the one that matches the selected platform:

```yaml
github: PUBLIC_SPONSOR_NAME
```

```yaml
ko_fi: PUBLIC_KOFI_NAME
```

```yaml
buy_me_a_coffee: PUBLIC_ACCOUNT_NAME
```

```yaml
custom: "https://public.example/donate"
```

After the destination is active, add `.github/FUNDING.yml`, replace the README's
temporary funding sentence with the public donation link, run the repository
audit, and publish both changes together.

The visual identity shared with hhGuide uses near-black, petrol teal, bright
teal, warm orange, and cream: `#01080b`, `#072932`, `#22c9b7`, `#ff7636`, and
`#ffdda9`. Keep future repository artwork within that palette so GRMCRKRS
projects remain recognizable without adding personal branding to the operating
system image itself.
